# 数据卡

## 当前数据

项目当前包含两份用于验证网页流程的 UTF-8 文本，以及一份技能词典：

- `sample_resumes/sample_resume.txt`：合成的 Python 后端实习生简历。
- `sample_jds/sample_python_backend.txt`：合成的 Python 后端岗位描述。
- `skills.json`：项目自编的版本化技能分类与中英文别名词典，供技能提取和差距分析使用；它不是完整行业标准，也不包含能力等级标签。
- `experience_keywords.json`：项目自编的经历、职责与教育要求关键词词典，不用于推断工作年限。
- `evaluation/synthetic_fusion_scores.csv`：12 条明确标记为 `synthetic_demo` 的预计算子分数，其中 8 条验证记录、4 条测试记录，仅用于验证权重搜索程序链路。
- `evaluation/synthetic_evaluation_scores.csv`：24 条明确标记为 `synthetic_demo` 的流程测试记录，包含固定验证/测试切分、3 个岗位类别和6个查询组；程序不会据此保存正式相关性、排序或分类指标。

两份文本均为项目自编的合成演示数据，不对应真实个人、学校、企业或招聘岗位，也不能用于声明模型在真实招聘场景中的性能。

## 使用边界

- 当前数据只用于功能演示和自动化测试。
- 技能词典用于可解释的字符串匹配，不应被解释为候选人的真实熟练度、工作年限或岗位胜任力。
- 合成权重实验数据及其误差结果不能用于声称真实招聘性能、最优权重或泛化能力。
- 合成完整评估数据只用于自动化测试和接口检查；正式指标表在当前状态下仅保留表头。
- 当前尚无人工标注的验证集或测试集。
- 当前不得计算或报告真实 Pearson、Spearman、NDCG@5、MRR、Accuracy、Precision、Recall 或 F1。
- 后续新增数据必须记录来源、获取日期、许可或授权状态、是否合成以及去标识化情况。

## 后续标注计划

正式评估数据将按岗位类别分组，并划分为互不重叠的验证集和测试集。融合权重只在验证集选择；最终测试集只用于一次性报告，不用于调参。
